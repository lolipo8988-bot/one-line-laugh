# one-line-laugh

One funny line for make.fun's The One-Line Laugh bounty — a single
sentence about a standing desk bought to be healthier, with the surprise
landing at the very end.

## How it works

`main.py` (Python 3.13) writes one text of 73 Unicode code points to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=/tmp/laugh-out python3 main.py
cat /tmp/laugh-out/entry.txt
```
